# Hero image

Drop one image here, then set `image` (and optionally `imageAlt`) on the
`"hero"` entry in `src/data/homepage-sections.json` to the path below.

| Field | Value |
|---|---|
| Recommended filename | `technician-servicing-appliance.jpg` |
| Path to set in data | `/images/hero/technician-servicing-appliance.jpg` |
| Aspect ratio | 4:3 (the component crops to this ratio automatically) |
| Recommended size | at least 1200×900px, JPG or WebP, optimized for web (target well under 300KB) |
| Subject | A technician servicing a home appliance (AC, washing machine, kitchen appliance, etc.) — professional, well-lit, matches the "certified technician" brand promise |
| Must NOT be | Any Urban Company photo/asset, or any image you don't hold a license to use |

Until a real file is added here, the homepage shows a polished neutral
gradient placeholder instead of a broken image — no code change is needed
when you do add the file, only the `image` field in the data.
